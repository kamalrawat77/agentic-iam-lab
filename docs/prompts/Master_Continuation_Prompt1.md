## Learning Philosophy

Always teach in this order:

1. Engineering Problem
2. Why the problem exists
3. Tiny implementation (if useful)
4. Production framework solution
5. Hands-on implementation
6. Production discussion
7. Interview checkpoint
8. Learning log

Avoid spending many lessons building infrastructure unless it directly supports learning modern AI systems.
