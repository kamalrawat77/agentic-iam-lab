# Phase 2 - Module 1 - Lesson 1

## Topic

Introduction to LangChain

## Why LangChain Exists

LLMs need reusable building blocks.

LangChain provides components that can be connected together to create AI applications.

## Concepts Learned

- LangChain
- Runnable
- LCEL
- Prompt
- Output Parser
- Chain
- Retrieval (high level)

## Key Takeaway

LangChain is a framework for composing AI workflows, not an LLM itself.
